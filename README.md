# Abdur Rafay — Personal Portfolio

A five-page personal portfolio site with a Minecraft-inspired pixel-art theme . Built with plain HTML and CSS — no frameworks, no build step.

## Pages
index.html (Main home page)
gallery.html
hobbies.html
contact.html
skills.html

## Running locally

This is a static site — no build or install step needed. Any of the following works:

- **VS Code Live Server**: right-click `index.html` → "Open with Live Server", or use the "Go Live" button with `index.html` as the workspace root.


## Notes

- Fonts (`Press Start 2P`, `VT323`) load from Google Fonts via `@import` in `styles.css`, so an internet connection is needed for the pixel-font look.
